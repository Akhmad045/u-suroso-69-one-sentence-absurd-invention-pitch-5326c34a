One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: a toaster that fires each slice out on a tiny parachute, so your toast can never land butter-side down. `main.py` (Python 3.13, standard library only, no network) writes the sentence to `/output/entry.txt`, with a gate that checks it is one non-blank sentence of 1–220 UTF-8 characters and verifies the written file round-trips exactly.
